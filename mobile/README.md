# تطبيق زاوية — أندرويد وiOS

تطبيق أصلي للتاجر بنفس هوية المنصة ونفس كل ميزة فيها، مبني بـ Capacitor 8.

---

## الفكرة في سطرين

التطبيق **بيشغّل المنصة الحيّة نفسها** (`www.zawyaeg.site`) جوّه WebView أصلي، وفوقها
**طبقة تطبيق** بتضيف اللي الموقع ما يقدرش يعمله.

ليه مش نسخة منفصلة؟ المنصة كلها منطق على الخادم (جلسات، أفعال خادم، قاعدة
بيانات، مفاتيح مشفّرة). أي نسخة «مستقلة» كانت هتبقى تطبيق تاني بيتكتب من الأول
وبيتأخر عن الويب مع كل ميزة. هنا **أي ميزة بتنزل على الموقع بتظهر في التطبيق
في نفس اللحظة** — من غير تحديث من المتجر.

## اللي التطبيق بيضيفه فوق الموقع

| الميزة | التفاصيل |
|---|---|
| شاشة افتتاح متحركة | الشعار بيصحى من شاشة النظام، بتوهّج ولمعة، لحد ما اللوحة تجهز |
| تعريف بالتطبيق | ٣ شرائح بالسحب لأول مرة (للي مالوش جلسة)، وتودّي على «افتح متجرك» أو «دخول» |
| حركة بين الصفحات | دخول ناعم للصفحة + شريط تقدّم بألوان الهوية |
| شريط سفلي أصلي | مؤشر الصفحة الحالية بيتنطط بحركة، والأيقونة بتنضغط مع اللمس |
| اهتزاز خفيف | مع الأزرار والتبويبات والسحب |
| السحب للتحديث | بمؤشر بالهوية ومقاومة زي التطبيقات الأصلية |
| زرار الرجوع (أندرويد) | بيقفل القايمة المفتوحة الأول، وبعدين يرجع، وفي البداية «اضغط تاني للخروج» |
| السحب من الطرف للرجوع (iOS) | زي أي تطبيق iOS |
| شريط الحالة بلون الصفحة | أبيض في اللوحة، بنفسجي في الدخول، والأيقونات بتتقلب فاتح/غامق |
| الوضع الداكن | بيتبع الجهاز أو اختيار التاجر في المنصة |
| التنزيل والحفظ | التصدير والملفات بتتحفظ في «التنزيلات/Zawya» (أندرويد) أو «الملفات» (iOS) |
| المشاركة الأصلية | صور البوستات والروابط بشاشة المشاركة بتاعة الجهاز |
| الطباعة | الفواتير بتتطبع من طابعة الموبايل |
| الكاميرا | «صوّر» جنب «اختار من المعرض» عند رفع صور المنتجات |
| من غير نت | صفحة بالهوية بتحاول توصل لوحدها، وتنبيه لو النت قطع وإنت جوّه |
| رجوع بعد غياب | لو التطبيق فضل في الخلفية أكتر من نص ساعة، البيانات بتتحدّث |
| الروابط | المنصة جوّه التطبيق، المتاجر والمواقع في متصفح داخلي، واتساب والسوشيال في تطبيقاتهم |
| روابط عميقة | `zawyaeg.site/dashboard/...` و `zawya://...` بيفتحوا التطبيق |

## البنية

```
mobile/
  capacitor.config.ts     الإعدادات (الموقع، الألوان، الإضافات)
  src/layer/              طبقة التطبيق (TypeScript) — بتتحقن في كل صفحة
    index.ts              نقطة البداية
    launch.ts             شاشة الافتتاح
    onboarding.ts         التعريف بالتطبيق
    navigation.ts         الحركة، الرجوع، الروابط العميقة
    chrome.ts             شريط الحالة والـviewport
    files.ts              التنزيل والمشاركة والطباعة
    gestures.ts           الاهتزاز والسحب للتحديث
    network.ts            حالة الاتصال
  www/                    صفحات محلية (مفيش نت) + ناتج بناء الطبقة
  resources/source/       الشعار الأصلي — منه بتتولّد كل الأيقونات
  scripts/                بناء الطبقة وتوليد الأيقونات
  android/                مشروع أندرويد
    .../ZawyaShellPlugin.java   الطبقة الأصلية (حقن، روابط، ملفات، ألوان)
  ios/                    مشروع iOS
    .../ZawyaShellPlugin.swift  نفس الدور على iOS
    .../ZawyaViewController.swift
  store-assets/           أيقونة وصورة الواجهة لجوجل بلاي
```

**قاعدة:** الطبقة ما بتغيّرش أي منطق أو بيانات في المنصة. لو فشلت بالكامل،
التطبيق بيفضل شغّال كموقع كامل.

## الأوامر

```bash
npm install
npm run sync          # يبني الطبقة وينسخها للمشروعين — بعد أي تعديل في src/layer
npm run assets        # يولّد الأيقونات وشاشات البداية — بعد تغيير الشعار
npm run typecheck
npm run android:open  # يفتح Android Studio
npm run ios:open      # يفتح Xcode (على ماك)
```

## بناء أندرويد

### من GitHub (الأسهل)
كل push على `mobile/` بيشغّل **تطبيق أندرويد** في Actions وبيطلّع:
- `app-release.apk` — تتسطّب مباشرة على أي موبايل أو تترفع على أي موقع
- `app-release.aab` — للرفع على جوجل بلاي
- `app-debug.apk` — للتجربة

عشان النسخ تطلع **موقّعة**، ضيف الأسرار دي في
Settings ← Secrets and variables ← Actions:

| السر | القيمة |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | محتوى `release.keystore.base64.txt` |
| `ANDROID_KEYSTORE_PASSWORD` | من `keystore.properties` |
| `ANDROID_KEY_ALIAS` | `zawya` |
| `ANDROID_KEY_PASSWORD` | من `keystore.properties` |

### محليًا على ويندوز
Android Studio أو سطر الأوامر:
```bash
cd android
./gradlew assembleRelease bundleRelease
```
> مسار المشروع فيه حروف عربية، وJava على ويندوز مش بتقراه. الحل: خريطة
> المجلد على حرف درايف (`subst Z: "المسار"`) والبناء من `Z:\mobile\android`.

## ⚠ مفتاح التوقيع

`android/release.keystore` و `android/keystore.properties` **خارج git**.
نسخة احتياطية منهم في `H:\for claude\zawya-tools\signing`.

**لو المفتاح ضاع، التطبيق ما يقدرش يتحدّث على جوجل بلاي تاني أبدًا** — أي تحديث
لازم يتوقّع بنفس المفتاح. احفظ نسخة في مكان آمن (درايف مشفّر، مدير كلمات سر).

> لو هتفعّل Play App Signing (المفضّل)، المفتاح ده بيبقى «مفتاح الرفع» وجوجل
> بتقدر تستبدله لو ضاع.

## الرفع على جوجل بلاي

1. [play.google.com/console](https://play.google.com/console) — حساب مطوّر (٢٥ دولار مرة واحدة)
2. Create app ← الاسم «زاوية» ← App ← Free
3. Store listing: الأيقونة `store-assets/play-icon-512.png`، صورة الواجهة
   `store-assets/play-feature-1024x500.png`، وسكرين شوت من الموبايل
4. Privacy policy: `https://www.zawyaeg.site/privacy`
5. Data safety: الحساب (بريد، اسم)، صور يرفعها التاجر، ومفيش مشاركة مع أطراف تالتة
6. Production ← Create release ← ارفع `app-release.aab`

## الروابط العميقة (App Links)

عشان روابط `zawyaeg.site/dashboard` تفتح التطبيق مباشرة من غير سؤال، الموقع
لازم يعلن إن التطبيق تبعه. الملف جاهز في `public/.well-known/assetlinks.json`
بمشروع الويب — بيشتغل أول ما الموقع يتنشر.

## iOS

المشروع كامل وجاهز، لكن **البناء لازم على ماك** (قيد من Apple).

- **GitHub:** كل push بيشغّل **تطبيق iOS** على ماك من GitHub وبيتأكد إن المشروع
  بيتبني، وبيطلّع نسخة محاكي.
- **النسخة للآب ستور:** محتاجة حساب Apple Developer (٩٩ دولار/سنة). على ماك:
  ```bash
  npm install && npm run sync && npm run ios:open
  ```
  Xcode ← Signing & Capabilities ← اختار الفريق ← Product ← Archive ← Distribute App.

## اللي لسه (المرحلة الجاية)

- **إشعارات الطلبات الجديدة (Push):** محتاجة مشروع Firebase (مجاني) + مفتاح APNs
  من حساب Apple + جدول أجهزة وإرسال من الخادم في المنصة. الأساس (الإضافات
  الأصلية) جاهز يتركّب عليه.
- **قفل بالبصمة/الوش** للّوحة.
- **Universal Links على iOS:** محتاجة Team ID من حساب Apple.
