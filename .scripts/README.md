# أدوات محلية

سكربتات تشغيل — **مش جزء من التطبيق**. كلها بتقرا `DIRECT_URL` من
`.env.local`، يعني **بتشتغل على قاعدة الإنتاج**. اقرا الوصف قبل ما
تشغّل أي واحد.

## `apply-sql.mjs`

بيشغّل ملف هجرة مكتوب بإيد، جملة جملة.

```bash
node .scripts/apply-sql.mjs drizzle/0022_couriers.sql
```

بيقسّم الملف على `--> statement-breakpoint` زي ما drizzle بيعمل.

**ليه ده موجود:** المخطط بيتطبّق بـ`db:push` لا بـ`migrate`، فلقطة
`drizzle/meta` متأخرة عن القاعدة. الهجرات هنا مكتوبة بإيد وidempotent،
وما كانش فيه حاجة تشغّلها غير النسخ واللزق في محرّر Supabase.

## `test-account.mjs` · `test-order.mjs` · `test-events.mjs`

بيعملوا متجر تجربة اسمه `zwverifytmp` وطلبًا وأحداث زيارات فيه —
عشان الشاشة الجديدة تتفتح بعين قبل ما تترفع.

```bash
node .scripts/test-account.mjs create   # الحساب والمتجر
node .scripts/test-order.mjs            # طلب مؤكّد فيه بنود وعنوان
node .scripts/test-events.mjs           # ٤٢ حدث زيارة على مدار ساعة
node .scripts/test-account.mjs drop     # يمسح المتجر والحساب
```

**`drop` بيمسح المتجر بالكامل** — بالطلبات والأحداث اللي جوّاه.
مربوط بـ`slug = 'zwverifytmp'` وحده، فما بيلمسش أي متجر تاني.

**ليه ده موجود:** البناء اللي بيعدّي مش دليل إن الصفحة بترسم. صفحة
اتبعت فيها أيقونة من مكوّن خادم لمكوّن عميل بتعدّي `tsc` و`next build`
الاتنين، وبترمي وقت التصيير بس. القاعدة بقت: **ما تترفعش صفحة
ما اتفتحتش**.
